Backseat Transit Doodle Letter Poster Style

Transit photos turned into energetic hand-lettered travel posters.

★ Star on GitHub Open in gallery View on GitHub

4 example cases

Same style.json, different subjects. Each case's values are in the examples section of the JSON.

What this style does

A realistic passenger-seat transport photo transformed into a high-energy travel poster with a central rear-view subject, electric yellow silhouette halo, oversized yellow-orange hand-drawn letters, comic rays, purple music marks, sticker icons, and cyan-white cloud swooshes.

Signature traits

  • Preserve the core visual identity: A realistic passenger-seat transport photo transformed into a high-energy travel poster with a central rear-view subject, electric yellow silhouette halo, oversized yellow-orange hand-drawn letters, comic rays, purple music marks, sticker icons, and cyan-white cloud swooshes.
  • Use BACKGROUND_ELEMENTS as the documentary background details and secondary context.
  • Use a realistic passenger-seat travel photo as the base layer: wide-angle backseat perspective, real vehicle interior, natural daylight through the windows, visible material texture, dashboard and window framing, and a believable road-trip or local transit moment.
  • Use golden yellow fills, orange shadow shapes, burnt brown outlines, and sticker-like flat 2D finish.
  • Use MAIN_TEXT as the large illustrated word integrated into the composition.
  • Keep the same visual genre, density level, and rendering mode across new subjects.

How to use

  1. Copy the style.json below.
  2. Paste it into ChatGPT, Gemini or Claude, or any LLM image workflow (Nano Banana Pro, GPT Image, Midjourney).
  3. Swap the variables for your own subject and generate.

Variables

  • SUBJECT subject
  • SUBJECT_ACTION subject action
  • PRODUCT_OR_PROP product or prop
  • LOCATION location
  • BACKGROUND_ELEMENTS background elements
  • MAIN_TEXT main text
  • SECONDARY_TEXT secondary text
  • ACCENT_SYMBOL accent symbol
  • WARDROBE_STYLE wardrobe style
  • ASPECT_RATIO aspect ratio
