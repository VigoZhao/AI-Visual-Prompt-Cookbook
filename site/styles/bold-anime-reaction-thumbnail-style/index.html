Bold Anime Reaction Thumbnail Style

High-impact anime thumbnails with bold yellow reaction typography.

4 example cases

Same style.json, different subjects. Each case's values are in the examples section of the JSON.

What this style does

A high-impact anime web-thumbnail system with oversized reaction characters, bold yellow headline typography, hard black shadows, split-screen framing, a smaller glowing action insert, and clean cel-shaded illustration.

Signature traits

  • Preserve the core visual identity: A high-impact anime web-thumbnail system with oversized reaction characters, bold yellow headline typography, hard black shadows, split-screen framing, a smaller glowing action insert, and clean cel-shaded illustration.
  • Use clean glossy cel-shaded anime rendering, crisp black line art, smooth gradients, and bright commercial lighting.
  • Use cool blue/cyan backgrounds, warm character colors, high-contrast black outlines, and a small yellow arrow or glow marker.
  • Use new subjects, new scene details, new props or products, and new text, while preserving the style fidelity anchors.
  • Keep the same visual genre, density level, and rendering mode across new subjects.
  • Preserve the original balance between main subject, typography, decorative marks, and background texture.

How to use

  1. Copy the style.json below.
  2. Paste it into ChatGPT, Gemini or Claude, or any LLM image workflow (Nano Banana Pro, GPT Image, Midjourney).
  3. Swap the variables for your own subject and generate.

Variables

  • SUBJECT subject
  • SUBJECT_ACTION subject action
  • PRODUCT_OR_PROP product or prop
  • LOCATION location
  • BACKGROUND_ELEMENTS background elements
  • MAIN_TEXT main text
  • SECONDARY_TEXT secondary text
  • ACCENT_SYMBOL accent symbol
  • WARDROBE_STYLE wardrobe style
  • STYLE_FIDELITY_ANCHORS style fidelity anchors
  • SOURCE_CONTENT_TO_AVOID source content to avoid
  • ASPECT_RATIO aspect ratio
  • NEGATIVE_PROMPT negative prompt
